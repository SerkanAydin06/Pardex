Ayarlar

Oyun proje klasöründen açılırken kullanılır. Godot'u açtığın .exe dosyası.
Anahtar nasıl alınır?
  1. Bu bağlantıyı aç (GitHub hesabınla). Token name: PARDEX, Expiration: istediğin süre.
  2. Repository access → Only select repositories → listeden SerkanAydin06/Pardex'i seç.
  3. Permissions bölümünde Contents iznini bul (gerekirse Add permissions'a bas) ve Read and write yap.
    "Read-only" kalırsa çalışmaz.
  4. Generate token'a bas, çıkan anahtarı buraya yapıştır ve Kaydet'e bas.
Anahtar yalnızca bu bilgisayarda saklanır; arkadaşlarının sunucunu otomatik bulması için kullanılır.
